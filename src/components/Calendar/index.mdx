# Calendar

The Calendar component displays the current month and year, along with day
buttons for date selection.

## Usage guidance

Use a calendar when:

- Users need to choose a date from a calendar view.
- You are building a custom date input that includes date selection.

Avoid using a calendar when none of the above applies.

## Accessibility

Users should be able to go to the previous month, go to the next month, and
choose a date using only a keyboard.

## Basic usage

Click a day to select it. Use the next and previous buttons to move between
months.
