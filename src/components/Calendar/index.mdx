# Calendar

`Calendar` displays the current month and year, along with day
buttons for date selection.

## Usage guidance

Use a calendar when:

- Users need to choose a date from a calendar view.
- You are building a custom date-selection interface.

Avoid using a calendar when a standard date input provides a simpler
experience.

## Accessibility

Users should be able to go to the previous month, go to the next month, and
choose a date using only a keyboard.

Consumers are responsible for giving icon-only navigation controls accessible
names, such as `aria-label="Previous month"` and `aria-label="Next month"`.
When `Calendar` is used as an application calendar or date-picker pattern,
consumers must also provide the appropriate roles, selected-date semantics,
instructions, and keyboard behavior for that use case.

## Basic usage

Click a day to select it. Use the next and previous buttons to move between
months.

## Props

### Calendar

Accepts standard props for an HTML `<div>` element, except `value` and
`onChange`. Supply the selected date through `value` and receive new selections
through `onChange`.

Based on `React.HTMLAttributes<HTMLDivElement>`.

<ArgTypes of={Calendar} />

### Calendar.Header

Accepts standard props for an HTML `<div>` element:
`React.HTMLAttributes<HTMLDivElement>`.

### Calendar.Left

Accepts standard props for an HTML `<button>` element:
`React.ButtonHTMLAttributes<HTMLButtonElement>`.

Native `onClick` handlers receive the button's mouse event and run alongside
the built-in month navigation. Calling `event.preventDefault()` prevents the
navigation.

### Calendar.Right

Accepts standard props for an HTML `<button>` element:
`React.ButtonHTMLAttributes<HTMLButtonElement>`.

Native `onClick` handlers receive the button's mouse event and run alongside
the built-in month navigation. Calling `event.preventDefault()` prevents the
navigation.

### Calendar.Title

Accepts standard props for an HTML `<div>` element:
`React.HTMLAttributes<HTMLDivElement>`.

### Calendar.Weekdays

Accepts standard props for an HTML `<div>` element:
`React.HTMLAttributes<HTMLDivElement>`.

### Calendar.Weekday

Accepts standard props for an HTML `<div>` element:
`React.HTMLAttributes<HTMLDivElement>`.

### Calendar.Days

Accepts standard props for an HTML `<div>` element:
`React.HTMLAttributes<HTMLDivElement>`.

### Calendar.Day

Accepts standard props for an HTML `<button>` element, except the native
`value`. Supply the represented date through `value`. `Calendar` reports
selected dates through its root `onChange`, while native `onClick` handlers
receive the button's mouse event. Default days outside the displayed month are
disabled.

Based on `React.ButtonHTMLAttributes<HTMLButtonElement>`.
