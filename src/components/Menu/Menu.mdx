# Menu

The Menu component displays a list of options that users can choose from.

## Usage guidance

Use a menu when:

- Users need to choose an option.
- Users do not need to see all options at all times.

Avoid using a menu when users should always see all available options.

## Accessibility

Menu toggles should show a visible focus state. Users should be able to open the
menu, choose an option, and close the menu using only a keyboard. They should
also be able to understand whether the menu is currently open.

## Basic usage

Click the button to open the menu. Then choose an option, click outside the menu, or press
Esc to close it.
