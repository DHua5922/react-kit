# Modal

The Modal component displays popup content when triggered by a user action.

## Usage guidance

Use a modal when:

- Users do not need to see the content at all times.

Avoid using a modal when users should always see the content.

## Accessibility

When a modal is shown, focus should automatically move into the modal.
Users should be able to navigate through the modal content and close the
modal using only a keyboard. They should also be able to understand whether
the modal is currently open.

## Basic usage

Click the button to open the modal. Then click outside the modal, click the
close button, or press Esc to close it.

## Props

### Modal

Accepts all standard props for an HTML `<dialog>` element:
`React.HTMLAttributes<HTMLDialogElement>`.

### Modal.Header
