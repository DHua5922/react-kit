# Modal

`Modal` presents focused content in a native modal dialog.

## Usage guidance

Use a modal when users must complete or acknowledge a focused task before
returning to the underlying page.

Avoid using a modal for nonessential information or interactions that can
remain within the normal page flow.

## Accessibility

When a modal opens, focus moves into it. Users should be able to navigate its
content and close it using only a keyboard.

Consumers are responsible for providing an accessible name for icon-only
controls, such as `Modal.CloseButton`, using `aria-label` or visible text.
Consumers must also give the dialog itself an accessible name, typically by
connecting `Modal.Title` with `aria-labelledby` or by supplying `aria-label`.

## Basic usage

Click the button to open the modal. Then click the close button or press Escape
to close it.

## Props

### Modal

Accepts standard props for an HTML `<dialog>` element:
`React.DialogHTMLAttributes<HTMLDialogElement>`.

<ArgTypes of={Modal} />

### Modal.Header

Accepts standard props for an HTML `<div>` element:
`React.HTMLAttributes<HTMLDivElement>`.

### Modal.CloseButton

Accepts standard props for an HTML `<button>` element:
`React.ButtonHTMLAttributes<HTMLButtonElement>`.

### Modal.Title

Accepts standard props for an HTML `<h2>` element:
`React.HTMLAttributes<HTMLHeadingElement>`.

### Modal.Body

Accepts standard props for an HTML `<div>` element:
`React.HTMLAttributes<HTMLDivElement>`.

### Modal.Footer

Accepts standard props for an HTML `<div>` element:
`React.HTMLAttributes<HTMLDivElement>`.
