# Popup

`Popup` displays contextual content in a portal.

## Usage guidance

Use a popup when:

- Content should appear only when needed.
- Content should not be shown immediately.

Avoid using a popup when content should always be shown.

## Accessibility

`Popup` provides portal rendering, positioning, outside-click dismissal, and
Escape-key dismissal. It does not assign an accessibility role because the
appropriate semantics depend on the content.

Consumers are responsible for supplying an appropriate role, accessible name,
trigger relationship, focus behavior, and role-specific keyboard interactions.
For example, content used as a menu must implement the complete menu pattern;
content used as a custom select must implement the complete select or combobox
pattern.

## Positioning

`Popup` uses the coordinates supplied by its consumer. It does not automatically
flip or shift content to avoid viewport edges. Keep popup dimensions and offsets
within the available viewport, or use a collision-aware positioning solution
when the interface requires automatic placement.

## Basic usage

Click the button to open the popup. Click outside it or press Escape to close
it.

## Props

### Popup

Accepts standard props for an HTML `<div>` element:
`React.HTMLAttributes<HTMLDivElement>`.

Use `open` with `onOpenChange` to control visibility.
